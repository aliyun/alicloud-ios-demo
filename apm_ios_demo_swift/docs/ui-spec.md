# Demo UI Spec

本规范直接对应当前 Demo 的实现参数。新增页面或改造既有页面时，默认复用同一套 token 和组件样式，不再按页面单独定义。

## 1. 页面骨架

| 语义 | 规范值 |
| --- | --- |
| 页面左右边距 | `16` |
| 二级页返回按钮顶部间距 | `10` |
| 返回按钮与标题间距 | `4` |
| 二级页标题栏底部留白 | `20` |
| 标题栏后首个内容块顶部间距 | `4` |
| 分组标题距离上一块内容 | `20` |
| 分组标题距离内容区 | `14` |
| 表单标题距离输入框 | `6` |
| 同组输入项垂直间距 | `12` |
| 输入区与主按钮间距 | `20` |
| 页面底部留白 | `32` |

## 2. 字体层级

| 语义 | 规范值 |
| --- | --- |
| 二级页标题 | `22 / Medium / kern 0.8` |
| 分组标题 | `18 / Medium` |
| 表单标题 | `18 / Regular / line-height 24 / kern 0.2` |
| 提示文案 | `15 / Regular / line-height 20 / kern 0.2` |
| 正文文案 | `16 / Regular / line-height 24` |
| 次级操作按钮文案 | `16 / Regular / line-height 24` |
| 主按钮文案 | `18 / Semibold` |
| Toast 文案 | `15 / Medium` |
| 居中弹窗标题 | `20 / Semibold` |
| 居中弹窗正文 | `15 / Regular / line-height 24` |
| 底部引导标题 | `20 / Medium / kern 0.4` |

## 3. 组件规范

| 组件 | 规范值 |
| --- | --- |
| 提示卡片 | 圆角 `8`，左右内边距 `16`，上下内边距 `14` |
| 输入框容器 | 高 `52`，圆角 `8`，左右内边距 `16` |
| 次级操作卡片/按钮 | 高 `48`，圆角 `8`，边框 `2` |
| 主按钮 | 高 `60`，圆角 `8` |
| 分组指示条 | `4 x 20`，圆角 `3` |
| Toast | 底部 `28`，圆角 `12`，左右内边距 `18`，上下内边距 `12` |
| 居中弹窗 | 圆角 `20`，宽度 `min(屏宽-32, 344)`，内容左右内边距 `20`，按钮区高 `52` |
| 底部引导面板 | 顶部圆角 `22`，标题左右内边距 `24`，内容左右内边距 `16` |
| 底部引导状态卡 | 高 `40`，圆角 `8` |

## 4. 共享组件

| 组件 | 说明 |
| --- | --- |
| `EAPMDemoSecondaryPageHeaderView` | 二级页统一标题栏，包含返回按钮、标题字号和顶部/底部留白 |
| `EAPMDemoSectionHeaderView` | 统一分组指示条和分组标题 |
| `EAPMDemoTipCardView` | 统一提示卡的圆角、内边距和提示文案样式，可按页面配置边框 |
| `EAPMDemoInputFieldView` | 统一表单标题、输入容器、占位文案和只读态样式 |
| `EAPMDemoPrimaryButton` | 统一主按钮高度、圆角、字号和渐变背景 |
| `EAPMDemoSecondaryActionButton` | 统一首页功能卡、崩溃按钮、网络错误按钮的边框卡片样式 |
| `EAPMDemoToastPresenter` | 统一 Toast 位置、内边距、圆角和动效 |

## 5. 页面映射

| 页面 | 应用规范 |
| --- | --- |
| 首页 | Hero 区可保持独立视觉；信息 banner、分组标题、功能卡片必须复用共享组件 |
| 设置 | 标题栏、输入框、保存按钮、Toast 遵循页面骨架和组件规范 |
| 其它类型崩溃 | 标题栏、提示卡、分组标题、触发按钮遵循页面骨架和组件规范 |
| 启动分析弹窗 | 复用居中弹窗容器样式，内容可按业务使用强调文本 |
| 页面分析 | 标题栏、提示卡、正文段落遵循页面骨架和字体层级 |
| 网络分析 | 标题栏、提示卡、输入框、发送按钮、错误按钮遵循统一规范 |
| 居中弹窗 | 标题、正文、按钮区遵循弹窗规范 |
| 远程日志引导弹层 | 标题、状态卡、步骤说明、按钮遵循底部引导规范 |

## 6. 执行要求

- 新页面默认先套用这份规范，再做局部视觉差异化。
- 同语义组件必须优先复用共享 token 和共享组件，不允许重新定义字号、圆角、间距。
- 如确实需要偏离规范，必须在代码旁用注释说明原因，并同步更新本规范。
